# red-team-pressure-test

**What it is.** Dispatches a genuinely independent subagent with one job: find every gap, loophole, and weak assumption in a plan, ruthlessly, with no credit given for what's good about it. Not a self-critique — the context that wrote the plan is bad at finding its own blind spots, so the adversary has to come from outside it, gets the plan verbatim, and reports back a structured list instead of a diplomatic paragraph.

**What it's good for.** The plan, pitch, contract, or decision that's about to get presented and doesn't already run through a dedicated review lane. If the thing under scrutiny is a code change or a build plan, a `clodex`/TRIP-style pipeline or a `codex-plan-review`/`codex-code-review` pass already does this job — this skill is for everything else: strategy, client-facing commitments, anything belief- or business-shaped rather than code-shaped.

**Who it's for.** Anyone who'd rather have a subagent find the gap on a Tuesday afternoon than have a client or reality find it later, at a worse time. Pairs with `dialectical-review` (attacks a position) and `empirical-falsification` (attacks a fact) — this one attacks execution: what breaks, what was assumed, what nobody checked.
